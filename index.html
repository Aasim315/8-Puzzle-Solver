03 — THE ALGORITHM

How It Works

State-space search

Each tile arrangement is a state. Legal blank-tile moves connect states into a graph that the solver explores.

A* Search

A* prioritizes states by f(n) = g(n) + h(n). The path cost g(n) counts moves already made; the heuristic h(n) estimates moves remaining.

Manhattan Distance

For each numbered tile, add its horizontal and vertical distance to its goal cell. The blank is excluded. This admissible heuristic helps A* find an optimal path.

Solvability and optimal paths

For a 3×3 board, an even inversion count is solvable relative to the standard goal. With unit-cost moves and Manhattan Distance, A* returns a shortest solution.

Player moves measure your attempt. AI solution moves measure the optimal path found by the algorithm; they are separate metrics.
